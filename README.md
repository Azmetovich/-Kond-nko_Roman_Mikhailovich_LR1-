Для запуска проекта необходимо

Клонировать репозиторий:

bash
git clone https://github.com/Azmetovich/-Kondenko_Roman_Mikhailovich_LR1-.git
Открыть решение Pizza.sln в Microsoft Visual Studio (2019 или новее).


Проверить строку подключения к базе данных в файле App.config. Убедитесь, что база данных DBPizza доступна и развёрнута.

Собрать решение (Build Solution) и запустить проект (F5).

Использование (Usage)
После запуска приложения открывается окно авторизации (MainWindow).
В системе предусмотрено две роли:

Администратор: управление товарами (добавление, редактирование, удаление), управление сотрудниками, просмотр графика работы и истории заказов.

Сотрудник: просмотр каталога, добавление товаров в корзину, оформление покупки с сохранением PDF-чека (содержит QR-код), просмотр своего графика работы.

Основные сценарии:

Введите логин и пароль.

В зависимости от роли вы попадёте в AdminWindow или WorkerWindow.

Для оформления заказа перейдите в «Каталог», выберите товары, затем в «Корзину» и нажмите «Купить».

Назначение основных каталогов:

Views — содержит все графические окна приложения. Отвечает за отображение данных и взаимодействие с пользователем.

Entity — содержит сгенерированную модель Entity Framework (EDMX) для работы с базой данных.

Services — предназначена для вынесения бизнес-логики (работа с БД, генерация PDF, расчёты) из окон представления.

Infrastructure — предназначена для общих утилит, конвертеров и вспомогательных классов (например, MyFontResolver для PDF).

Данные (Data)
Приложение использует Entity Framework (подход Database First) для взаимодействия с базой данных Microsoft SQL Server.
Модель данных описана в файле DBPizza.edmx. Контекст базы данных (PizzaParovozovEntities) предоставляет доступ к таблицам: Users, Employees, Products, Ingredients, Carts, Orders, OrderProducts, WorkSchedules.
В файле App.xaml.cs создаётся статический экземпляр контекста App.Context, который используется во всём приложении.
